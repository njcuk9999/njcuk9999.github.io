Log in with a GitHub token

Changes are committed straight to the njcuk9999/njcuk9999.github.io repository, so you log in with a GitHub personal access token that is allowed to write to it. The token is your password: it stays in this browser and is only sent to GitHub.

First time: create the token

  1. Open GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Name it e.g. website admin and choose an expiration (you can make a new one when it runs out).
  3. Repository access: Only select repositories → njcuk9999.github.io.
  4. Permissions → Repository permissions → Contents: Read and write. Nothing else is needed.
  5. Generate it, copy it, paste it above. Keep it somewhere safe (e.g. a password manager); GitHub won't show it again.

Lost it or think it leaked? Delete it on the same GitHub page and create a new one.
